# 🎬 ویدیوی معرفی A-Cut 2Dpro (Remotion)

ویدیوی تبلیغاتی ۴۰ ثانیه‌ای نرم‌افزار **A-Cut 2Dpro** که با
[Remotion](https://www.remotion.dev) و React ساخته شده است:
افقی **1920×1080**، ‏۳۰ فریم‌برثانیه، کاملاً فارسی و راست‌چین (RTL) با فونت وزیرمتن.

## صحنه‌ها

| # | زمان | محتوا |
|---|------|-------|
| ۱ | ۰:۰۰–۰:۰۵ | لوگو و شعار «بهینه‌ساز هوشمند برش ورق» |
| ۲ | ۰:۰۵–۰:۱۱ | تایپ‌شدن قطعهٔ ۴۵۰×۱۵۰ و انتخاب عملیات لبه (نوار/فارسی ۴۵°/شیار با ورودی ۰/۱/۲) |
| ۳ | ۰:۱۱–۰:۱۸ | کلیک «محاسبهٔ چیدمان» و چیده‌شدن قطعات روی ورق + شمارندهٔ بهره‌وری |
| ۴ | ۰:۱۸–۰:۲۵ | نقشهٔ سیاه‌وسفید با پیکان‌های عملیات و هاشور پرت (+ زوم روی یک قطعه) |
| ۵ | ۰:۲۵–۰:۳۱ | خروجی‌ها: چاپ یک‌صفحه‌ای A4 ‏، فایل DXF برای CNC ‏، لیبل قطعات و PDF موبایل |
| ۶ | ۰:۳۱–۰:۳۶ | پلتفرم‌ها: وب (PWA) ‏، اندروید ‏، ویندوز — و ذخیرهٔ خودکار پروژه‌ها روی دستگاه |
| ۷ | ۰:۳۶–۰:۴۰ | دعوت به اقدام + سازنده (عباس کروشاد) + اینستاگرام/تلگرام `@Webxplusx` |

متن گویندگی صحنه‌به‌صحنه در [`VOICEOVER.md`](./VOICEOVER.md) و زیرنویس آماده
در [`subtitles.fa.srt`](./subtitles.fa.srt) است.

## پیش‌نیاز

- Node.js ‏۲۰ یا بالاتر
- اینترنت فقط برای نصب پکیج‌ها و دانلود خودکار Chromium در اولین رندر
  (فونت و لوگو داخل همین پوشه هستند، پس بقیهٔ کار آفلاین است.)

## دستورهای اصلی

```bash
cd promo-video
npm install

# ۱) پیش‌نمایش زنده و ویرایش در مرورگر (Remotion Studio)
npm run studio

# ۲) رندر ویدیوی نهاییِ بدون صدا — ۴۰ ثانیه (خروجی: out/A-Cut-2Dpro-promo.mp4)
npm run render

# ۲ب) رندر نسخهٔ صدادار با گویندگی فارسی — حدود ۵۳ ثانیه
npm run render:voiced
# خروجی: out/A-Cut-2Dpro-promo-voiced.mp4
# (فایل‌های صدای هر صحنه در public/voice/scene1.mp3 تا scene7.mp3 هستند؛
#  طول هر صحنه خودکار بر اساس مدت همان فایل تنظیم می‌شود)

# معادل مستقیم همان دستور:
npx remotion render src/index.ts Promo out/A-Cut-2Dpro-promo.mp4

# ۳) رندر یک فریم به‌صورت عکس (مثلاً پوستر ویدیو)
npm run render:poster
# یا هر فریم دلخواه:
npx remotion still src/index.ts Promo out/poster.png --frame=515
```

اولین رندر کمی طول می‌کشد چون Remotion مرورگر Chromium را دانلود می‌کند؛
رندرهای بعدی سریع‌ترند.

## شخصی‌سازی

- **زمان‌بندی صحنه‌ها:** آرایهٔ `SCENE_DURATIONS` در `src/Promo.tsx`
  (برحسب فریم؛ هر ثانیه = ۳۰ فریم).
- **متن‌ها و زیرنویس روی ویدیو:** کامپوننت `Caption` در انتهای هر فایل صحنه
  در `src/scenes/`.
- **قطعات روی نقشه (صحنهٔ ۳ و ۴):** `src/lib/layout.ts`
- **رنگ‌ها:** `src/lib/theme.ts` — **فونت:** `src/lib/font.ts` و فایل‌ها در `public/fonts`
- **لوگو:** `public/logo.png` (از آیکون خود برنامه گرفته شده است)

## صدای گوینده (نسخهٔ صدادار)

نسخهٔ صدادار آماده است: فایل نهایی `A-Cut-2Dpro-promo-voiced.mp4` در همین پوشه و
زیرنویس هم‌زمانش `subtitles-voiced.fa.srt`. صدای هر صحنه در
`public/voice/scene1.mp3` تا `scene7.mp3` است و کامپوزیشن جداگانهٔ
`PromoVoiced` در `src/Promo.tsx` طول هر صحنه را بر اساس مدت واقعی همان فایل
(آرایهٔ `AUDIO_SECONDS` — بعد از جایگزینی فایل‌ها این عددها را به‌روز کنید)
تنظیم می‌کند تا جمله‌ها نبرند. برای ضبط/تولید صدای تازه، به‌ازای هر صحنه یک
فایل جدا بسازید و در `public/voice/` جایگزین کنید؛ نمونهٔ دستی:

```tsx
import { Audio, Sequence, staticFile } from 'remotion';

// شروع هر صحنه (فریم): ۰، ‏۱۵۰، ‏۳۳۰، ‏۵۴۰، ‏۷۵۰، ‏۹۳۰، ‏۱۰۸۰
<Sequence from={150}>
  <Audio src={staticFile('voice/scene2.mp3')} />
</Sequence>
```

برای موزیک پس‌زمینه هم یک `<Audio>` جدا در ریشهٔ `PromoVideo` با
`volume={0.12}` اضافه کنید.

```text
├─ public/

│  ├─ scenes/               # هفت صحنهٔ ویدیو

└─ subtitles.fa.srt         # زیرنویس آماده برای آپلود در اینستاگرام/یوتیوب/…
```

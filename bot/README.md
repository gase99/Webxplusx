# ربات فروش لایسنس

نسخه فعلی پرداخت را خودکار بررسی نمی‌کند؛ مدیر پس از دریافت وجه، دکمه تأیید را می‌زند. لایسنس مادام‌العمر، مخصوص یک نصب و دارای امضای ECDSA P-256 است.

## راه‌اندازی
1. در BotFather ربات بسازید. نام واقعی آن را در `TELEGRAM_BOT_USERNAME` در `src/config/constants.ts` قرار دهید و برنامه را دوباره build کنید. نام فعلی فقط نمونه است.
2. روی سرور Python 3.10+ نصب کنید: `pip install -r bot/requirements.txt`.
3. متغیرهای `bot/.env.example` را در محیط سرویس تنظیم کنید. فایل `.env` خودکار خوانده نمی‌شود. توکن و کلید خصوصی را در Git یا چت قرار ندهید. `TELEGRAM_ADMIN_ID` باید شناسه عددی حساب شخصی مدیر باشد، نه نام کاربری.
4. `python3 bot/bot.py` را به‌صورت سرویس همیشه‌روشن اجرا کنید (فقط یک نمونه). دسترسی اینترنت به `api.telegram.org` لازم است. اگر webhook فعال بوده ابتدا آن را در API تلگرام حذف کنید تا polling کار کند.
5. مدیر باید ابتدا ربات را Start کند. مشتری شناسه نصب را ارسال می‌کند؛ پس از تأیید مدیر، کلید صادر و برای مشتری فرستاده می‌شود. تأیید تکراری همان کلید را دوباره می‌فرستد. ارسال مجدد شناسه توسط مشتری نیز کلید تأییدشده را بازیابی می‌کند.

## کلیدها و پشتیبان
در محیط توسعه `bot/private.pem` ساخته شده و عمداً در Git نیست؛ برای استقرار باید آن را امن به سرور منتقل کنید. از کلید خصوصی و `bot/licenses.sqlite` پشتیبان رمزگذاری‌شده بگیرید. اگر کلید موجود نیست یا برای انتشار جدید می‌خواهید تعویضش کنید:

```sh
python3 bot/generate_key.py
```

این دستور از بازنویسی کلید موجود جلوگیری می‌کند و JWK عمومی را چاپ می‌کند؛ آن را در `LICENSE_PUBLIC_KEY_JWK` جایگزین و برنامه را build کنید. تغییر کلید عمومی، لایسنس‌های قبلی را نامعتبر می‌کند. هیچ کلید خصوصی نباید داخل APK یا وب‌سایت منتشر شود.

## محدودیت‌های مهم
- پروژه یعنی شناسهٔ پروژه‌ای که با موفقیت ذخیره شده؛ ویرایش همان پروژه سهمیه مصرف نمی‌کند، «ذخیره با نام جدید» مصرف می‌کند. پس از ذخیرهٔ سوم، قفل ظاهر می‌شود. حذف پروژه سهمیه را برنمی‌گرداند.
- داده‌های پروژه پاک نمی‌شوند و پس از فعال‌سازی دوباره در دسترس‌اند.
- این قفل آفلاین در سمت کاربر است، نه DRM غیرقابل‌دورزدن: پاک‌کردن دادهٔ مرورگر/نصب و دستکاری برنامه می‌تواند دوره آزمایشی را ریست کند. شناسه، شناسهٔ نصب است نه شناسهٔ سخت‌افزاری. برای کنترل تجاری قوی باید سرور حساب کاربری و شمارش مرکزی اضافه شود.
- لایسنس آفلاین مادام‌العمر ابطال از راه دور ندارد. برای جابه‌جایی نصب باید مجدداً با مدیر هماهنگ شود.
- ربات در این محیط به تلگرام متصل یا روی سرور مستقر نشده است. نام ربات، شناسه مدیر و تنظیمات پرداخت باید توسط مالک تعیین شوند.
